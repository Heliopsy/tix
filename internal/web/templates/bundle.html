What goes into the file

Workflows, field definitions, tags, project templates and webhook endpoints. Never tasks, comments or artifacts, and never a webhook's signing secret: the endpoint arrives, its secret does not, so an imported webhook is inert until somebody gives it one.

Import a bundle

What an import changes

Nothing here is deleted. A component whose key is free is created.

A component whose key is already taken stops the import and asks what to do with it: skip keeps what is here, rename brings the incoming one in under a new key, and replace overwrites what is here with the incoming one.

Leave preview ticked to see what would happen. Nothing is written until you untick it.
