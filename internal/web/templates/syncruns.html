What this list does and does not contain

A row appears here when an import finishes. There is no separate record of a run: each row is read back out of the audit entry the import wrote when it completed, which is also why it can show the counts and the warnings at all.

Two kinds of run are therefore missing, and both are missing on purpose rather than by oversight. A dry run writes nothing, so it leaves nothing to list. A run that failed stops without writing a completion entry, so it does not appear either: what it leaves behind is a status of failed on its source, in the second table. If a source reads failed below with no matching row above, that is the run that failed.

A row also cannot show where the cursor stood after that particular run: the completion entry is written before the run fills its cursor in, so the value never reaches the trail. The second table shows where each source's cursor stands now, which is the question that usually matters.

The tasks an import created or updated are audited individually and show up in activity, attributed to the System actor.
