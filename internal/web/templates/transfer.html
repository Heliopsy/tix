A snapshot carries this tenant's work: its projects, tasks and their history. Configuration travels separately, under Components.

Export a snapshot

What goes into the file

Every task in the projects you name, with its status, priority, tags, dependencies and custom field values. Comments and artifacts are included only if you tick them. People, tokens, SSH keys and webhook secrets are never exported: a snapshot is safe to hand to another install without handing over credentials with it.

Import a snapshot

What an import changes

Merge adds what is new and updates what the snapshot carries. Anything already here that the snapshot does not mention is left alone.

Replace does that and then deletes, from the projects the snapshot covers, the tasks and field definitions it does not carry. It is how you make this tenant match the file exactly. Projects outside the snapshot are untouched either way.

Leave dry run ticked to see the counts first. Nothing is written until you untick it.
