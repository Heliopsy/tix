# Documentation

Guides for using and operating tix. The normative behaviour contract is in
[`openspec/`](../openspec/); these pages explain how to work with it.

Documentation is written in WP-51, once the behaviour it describes exists.

Until then, the specifications under
[`openspec/changes/tix-v1/specs/`](../openspec/changes/tix-v1/specs/) are the reference,
and `tix <command> --help` documents the CLI.
